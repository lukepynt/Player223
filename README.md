# Player 223

A 2D platformer game with creative mode and parkour challenges, developed by Javelin Studios.

## Features

- **Creative Mode**: Build your own custom maps with various block types
- **Parkour Mode**: Complete two pre-built parkour courses
- **Character Selection**: Choose between male and female characters with different armor sets
- **Dynamic Backgrounds**: Four background themes (Snow, Forest, Desert, Nighttime) each with different soundtracks
- **Build Mode**: Place and remove blocks in creative mode with keyboard shortcuts
- **Timer**: Track your completion times in parkour mode

## Controls

### Movement
- `A` - Move Left
- `D` - Move Right
- `Space` - Jump (hold for continuous jumping and wall jumping)

### Creative Mode
- `B` - Toggle Build Mode
- `1-9, 0, -` - Select block types
- `P` - Place Trophy (win condition)
- `V` - Place Lava (death trap)
- `K` - Change armour set
- `Left Click` - Place selected block
- `Escape` - Return to menu

### UI
- `U` - Start game after selection
- `Escape` - Toggle between game and menu

## Block Types

## Requirements

- .NET Framework 4.7.2
- Windows OS
- Visual Studio 2017 or later (for development)

## How to Run

1. Clone the repository
2. Open `PLAYER 223.sln` in Visual Studio
3. Build the solution
4. Run the application
